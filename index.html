Кластеризация: K-means, DBSCAN, GMM

Python · NumPy · scikit-learn · Jupyter Notebook

Реализация и сравнение алгоритмов кластеризации. Использование кластерных меток как признаков для supervised-модели (Lasso).

  • K-means: реализация с нуля, инициализации (Forgy, Random Partition, K-means++), Elbow method, Silhouette Score
  • DBSCAN: подбор ε и minPts, core/border/noise, кластеры произвольной формы
  • Agglomerative: дендрограмма, linkage-метрики (Single, Complete, Ward)
  • GMM + EM: Expectation-Maximization, типы ковариации, мягкая кластеризация
  • Feature engineering: кластерные метки как признаки, сравнение качества Lasso с/без кластерных признаков
K-means DBSCAN GMM EM

Нейронные сети: MLP с нуля

Python · NumPy · Jupyter Notebook

Реализация Multilayer Perceptron с нуля: forward pass, backpropagation, обучение на задаче бинарной классификации. Сравнение оптимизаторов и функций активации.

  • Архитектура: настраиваемое число скрытых слоёв и нейронов, сигмоида на выходе
  • Forward pass: линейные слои + активации (ReLU, Sigmoid, tanh, Cosine)
  • Backpropagation: ручной вывод градиентов через цепное правило, BCE + Sigmoid → градиент = ŷ − y
  • Оптимизаторы: SGD, Adam (momentum + RMSProp + bias correction)
  • Инициализация: Xavier/Glorot, He; анализ gradient vanishing/explosion
  • Теория: Universal Approximation Theorem (Cybenko)
MLP Backprop Adam с нуля
